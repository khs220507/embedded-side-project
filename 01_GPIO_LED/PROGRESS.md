## 상태와 핀 연결

| 상태 | LED | Arduino 핀 | STM32 GPIO |
|---|---|---|---|
| Idle | 초록 | D4 | PB5 |
| Running | 파랑 | D5 | PB4 |
| Warning | 노랑 | D6 | PB10 |
| Error | 빨강 | D7 | PA8 |

사용자 버튼 B1은 `PC13`, 보드 내장 LED LD2는 `PA5`에 연결되어 있다.

- STM32Cube 번들 설치 상태 확인

- ELF 펌웨어 빌드, 다운로드 및 검증
- B1 버튼으로 LD2와 PB5 출력 제어
- 주요 코드에 한국어 설명 주석 추가

## 현재 확인 상태

- 현재 4상태 LED와 50ms 버튼 디바운싱 소스의 Debug 빌드 성공
- `01_GPIO_LED.elf` 생성 성공
- RAM 1.68%, FLASH 1.55% 사용
- 초기 B1 입력과 LD2/PB5 제어는 실제 보드에서 확인
- 현재 4상태 순환과 네 LED 전체 동작은 별도 보드 검증 기록이 없어 추가 확인 필요
