# Project 01 — LED Status Controller

## 1. 회로 목표

NUCLEO-F401RE의 GPIO 출력으로 4개의 LED를 독립적으로 제어하고, 보드의
USER 버튼(B1)을 GPIO 입력으로 사용한다.

| 상태 | LED 색상 | NUCLEO 핀 | STM32 GPIO | 출력 논리 |
|---|---|---|---|---|
| Idle | 초록 | D4 | PB5 | HIGH일 때 켜짐 |
| Running | 파랑 | D5 | PB4 | HIGH일 때 켜짐 |
| Warning | 노랑 | D6 | PB10 | HIGH일 때 켜짐 |
| Error | 빨강 | D7 | PA8 | HIGH일 때 켜짐 |

입력은 보드에 내장된 USER 버튼 B1(PC13)을 사용한다. 별도의 버튼 회로는
필요하지 않다.

## 2. 필요한 부품

- NUCLEO-F401RE 1개
- 브레드보드 1개
- 초록, 파랑, 노랑, 빨강 LED 각 1개
- 220Ω 저항 4개
- M/M 점퍼선
- USB Mini-B 케이블

## 3. 배선

### 3.1 먼저 알아둘 핀 위치

보드의 USB Mini-B 단자가 위쪽을 향하게 놓는다. 보드 양옆의 검은색 Arduino
커넥터에 `D0`부터 `D15`, `A0`부터 `A5`, `POWER`가 인쇄되어 있다. 이번
회로에서는 Arduino 디지털 커넥터의 `D4`, `D5`, `D6`, `D7`과 POWER
커넥터의 `GND`를 사용한다.

`D4` 같은 이름은 보드에 인쇄된 커넥터 이름이고, `PB5` 같은 이름은 실제
STM32 MCU의 GPIO 이름이다. 예를 들어 D4와 PB5는 서로 다른 핀이 아니라
같은 전기적 연결점이다.

NUCLEO의 커넥터는 암 소켓이므로 **M/M 점퍼선**의 D한쪽 수 핀을 NUCLEO에,
다른 쪽 수 핀을 브레드보드에 꽂는다.

### 3.2 브레드보드 구조

- 바깥쪽 `+`, `-`로 표시된 긴 줄은 전원 레일이다.
- 가운데 단자 영역은 보통 같은 번호의 `a~e` 다섯 구멍끼리 연결된다.
- 중앙 홈을 건너는 `e`와 `f`는 서로 연결되지 않는다.
- 일부 브레드보드는 긴 전원 레일이 중간에서 끊겨 있다. 이번 회로는 한쪽
  구간만 사용하거나, 필요하면 점퍼선으로 두 구간을 연결한다.

이번 프로젝트에서는 `+` 전원 레일을 사용하지 않는다. 파란색 또는 `-`
레일 하나만 **공통 GND 레일**로 사용한다.

### 3.3 LED 방향 확인

- 긴 다리: 애노드(Anode, `+`) — GPIO/저항 방향
- 짧은 다리: 캐소드(Cathode, `-`) — GND 방향
- LED 몸체의 평평하게 깎인 면도 보통 캐소드 쪽이다.

다리 길이가 이미 잘려 구분되지 않으면 LED 내부에서 더 큰 금속판이 보이는
쪽을 캐소드로 판단할 수 있다. 확실하지 않으면 전원을 넣기 전에 LED를 새
것으로 교체하거나 멀티미터의 다이오드 모드로 확인한다.

### 3.4 기본 회로

각 LED를 아래와 같이 동일한 형태로 연결한다.

```text
NUCLEO GPIO ── 220Ω 저항 ── LED 애노드(긴 다리, +)
                              LED 캐소드(짧은 다리, -) ── 공통 GND 레일
                                                               │
NUCLEO GND ─────────────────────────────────────────────────────┘
```

저항은 방향이 없으므로 어느 쪽으로 꽂아도 된다. 또한 저항을 LED의 캐소드와
GND 사이에 놓아도 전기적 동작은 같지만, 이 문서에서는 실수를 줄이기 위해
항상 GPIO와 애노드 사이에 둔다.

상세 연결은 다음과 같다.

| 시작점 | 연결 부품 | 도착점 |
|---|---|---|
| D4 (PB5) | 220Ω → 초록 LED | GND |
| D5 (PB4) | 220Ω → 파랑 LED | GND |
| D6 (PB10) | 220Ω → 노랑 LED | GND |
| D7 (PA8) | 220Ω → 빨강 LED | GND |

NUCLEO의 GND 하나를 브레드보드의 공통 GND 레일에 연결하고, 네 LED의
캐소드를 모두 이 레일에 연결한다.

### 3.5 실제로 꽂는 순서

아래 행 번호는 예시다. 브레드보드의 빈 행이라면 다른 번호를 사용해도 된다.
중요한 것은 같은 행의 연결 관계다.

1. **USB 케이블을 아직 연결하지 않는다.**
2. NUCLEO의 `GND`와 브레드보드의 파란색 `-` 레일을 M/M 점퍼선으로 연결한다.
3. 초록 LED를 10번 행에 꽂되 두 다리가 서로 다른 연결 묶음에 들어가도록
   배치한다. 애노드는 `10e`, 캐소드는 중앙 홈 건너편 `10f`처럼 꽂으면 쉽다.
4. 초록 LED 캐소드가 있는 묶음에서 `-` 레일까지 점퍼선을 연결한다.
5. 220Ω 저항 한쪽을 초록 LED 애노드와 같은 묶음에 꽂고, 저항의 다른 쪽은
   비어 있는 행에 꽂는다.
6. NUCLEO `D4`에서 저항의 빈 쪽과 같은 묶음까지 점퍼선을 연결한다.
7. 같은 방식으로 파랑은 `D5`, 노랑은 `D6`, 빨강은 `D7`에 연결한다.

예시 배치는 다음과 같다.

| LED | LED 배치 예시 | GPIO 쪽 | 캐소드 쪽 |
|---|---|---|---|
| 초록 | 애노드 10e / 캐소드 10f | D4 → 220Ω → 10a~10e | 10f~10j → GND 레일 |
| 파랑 | 애노드 15e / 캐소드 15f | D5 → 220Ω → 15a~15e | 15f~15j → GND 레일 |
| 노랑 | 애노드 20e / 캐소드 20f | D6 → 220Ω → 20a~20e | 20f~20j → GND 레일 |
| 빨강 | 애노드 25e / 캐소드 25f | D7 → 220Ω → 25a~25e | 25f~25j → GND 레일 |

저항의 두 다리를 같은 `a~e` 묶음에 꽂으면 저항이 우회되어 아무 역할을 하지
못한다. 반드시 저항의 양쪽 다리가 서로 다른 행 또는 서로 분리된 묶음에
들어가게 한다.

### 3.6 완성된 연결을 신호별로 추적하기

```text
D4  → 220Ω → 초록 LED 긴 다리 → 초록 LED 짧은 다리 → GND
D5  → 220Ω → 파랑 LED 긴 다리 → 파랑 LED 짧은 다리 → GND
D6  → 220Ω → 노랑 LED 긴 다리 → 노랑 LED 짧은 다리 → GND
D7  → 220Ω → 빨강 LED 긴 다리 → 빨강 LED 짧은 다리 → GND
```

USER 버튼은 NUCLEO 보드에 이미 연결되어 있으므로 브레드보드에 추가로
배선하지 않는다.

## 4. 전원 및 주의사항

- 이 단계에서는 USB 케이블로 NUCLEO 보드에만 전원을 공급한다.
- LED를 5V 핀에 연결하지 않는다. GPIO 출력은 3.3V 기준이다.
- LED마다 반드시 220Ω 저항을 직렬로 연결한다.
- GPIO끼리 직접 연결하거나 GPIO를 GND/3.3V/5V에 직접 연결하지 않는다.
- 전원을 연결하기 전에 LED 방향과 GND 공통 연결을 확인한다.
- 배선을 변경할 때는 USB 케이블을 분리한다.

220Ω 사용 시 LED 전류는 순방향 전압에 따라 대략 5~7mA이며 GPIO 학습용
상태 표시 회로로 적합하다.

## 5. 전원 인가 전 체크리스트

- [ ] 네 LED의 긴 다리가 저항/GPIO 쪽에 연결되어 있다.
- [ ] 네 LED의 짧은 다리가 GND 레일에 연결되어 있다.
- [ ] 각 LED에 220Ω 저항이 하나씩 직렬 연결되어 있다.
- [ ] D4, D5, D6, D7 사이가 서로 단락되지 않았다.
- [ ] 브레드보드 GND 레일이 NUCLEO GND에 연결되어 있다.
- [ ] 브레드보드의 `+` 레일과 5V 핀에는 아무것도 연결하지 않았다.
- [ ] 저항의 양쪽 다리가 같은 브레드보드 연결 묶음에 꽂혀 있지 않다.

## 6. 회로 검증 순서

1. 초록 LED만 1초 간격으로 점멸한다.
2. 파랑, 노랑, 빨강 LED도 각각 단독 점멸시킨다.
3. 네 LED를 순서대로 점멸시킨다.
4. USER 버튼을 누를 때 상태를 다음 LED로 전환한다.
5. Idle, Running, Warning, Error 상태별로 지정된 LED 하나만 켠다.

### LED가 켜지지 않을 때

1. LED의 긴 다리와 짧은 다리가 반대로 꽂히지 않았는지 확인한다.
2. NUCLEO GND와 브레드보드 GND 레일이 연결됐는지 확인한다.
3. 코드에서 설정한 GPIO와 실제 D4~D7 배선이 일치하는지 확인한다.
4. 저항과 LED 다리가 브레드보드의 같은 연결 묶음을 공유하는지 확인한다.
5. 다른 색 LED 또는 새 LED로 한 채널만 다시 시험한다.

### LED가 항상 켜져 있거나 이상하게 동작할 때

1. GPIO가 `GPIO_Output`으로 설정됐는지 확인한다.
2. 점퍼선이 옆 핀에 잘못 꽂히지 않았는지 확인한다.
3. LED 채널 사이에 같은 브레드보드 행을 공유하지 않는지 확인한다.
4. 전원을 분리하고 배선을 한 채널씩 다시 추적한다.

회로 검증이 끝나면 STM32CubeMX에서 PB5, PB4, PB10, PA8을 `GPIO_Output`으로,
PC13을 입력으로 설정해 코드를 생성한다. 생성된 프로젝트는 STM32CubeIDE 또는
VS Code의 STM32 개발 도구로 빌드하고 보드에 다운로드한다.
