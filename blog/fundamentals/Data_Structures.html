STM32 자료구조: 배열과 문자열 Buffer

고정 길이 Command Buffer로 배열 Index, 문자열 끝 문자, 경계 검사를 학습한다.

기본 개념구현 목표핵심 코드동작 흐름실행 결과배운 점

기본 개념

C 문자열은 문자 배열의 마지막 \0으로 끝난다. 따라서 배열의 전체 용량을 문자 데이터에 모두 쓰면 안 된다.

문자 입력
→
CommandBuffer
→
완성된 명령

구현 목표

  • 고정 길이 char 배열에 명령을 저장한다.
  • length로 다음 저장 위치를 관리한다.
  • \n에서 명령을 완료하고, Overflow는 거부한다.

핵심 코드

typedef struct
{
    char data[COMMAND_BUFFER_CAPACITY];
    size_t length;
} CommandBuffer;

command_buffer_append()는 글자를 추가한 뒤 항상 \0을 기록한다. 용량이 16이면 실제 Payload는 15글자까지다.

동작 흐름

문자 추가
→
경계 검사
→
\n 확인
→
완료 또는 계속

경계를 넘으면 기존 Buffer는 유지하고 COMMAND_BUFFER_FULL을 반환한다.

실행 결과

  • arm-none-eabi-gcc의 엄격한 문법·경고 검사를 통과했다.
  • MSVC Build Tools에서 호스트 CMake 빌드와 CTest를 실행했고, 1개 테스트가 통과했다.
  • STM32 보드 검증은 하지 않았다. 다음 단계에서 UART DMA 수신 흐름에 연결한다.

배운 점

고정 배열의 경계 검사와 \0 예약은 임베디드 문자열 처리의 기본 안전 장치다. 원형 버퍼도 이 배열·Index·길이 관리 개념에서 출발한다.

한 줄 정리: 고정 길이 Command Buffer는 배열 범위를 지키면서 한 줄 명령을 모으는 가장 단순한 자료구조다.
