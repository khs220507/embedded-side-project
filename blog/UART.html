STM32 UART

USART2 송수신부터 인터럽트, 문자열 명령, printf 연결까지 정리한다.

구현 목표USART2 설정UART 송신printf 연결인터럽트 수신문자열 버퍼명령 처리정리

구현 목표

NUCLEO-F401RE의 USART2와 ST-LINK Virtual COM Port를 이용해 PC 터미널과 데이터를 주고받는다. UART 수신은 인터럽트 방식으로 처리하고, 한 글자씩 받은 데이터를 문자열 버퍼에 모아 LED 제어 명령으로 사용한다.

UART 송신

초기화가 끝난 뒤 시작 메시지와 현재 LED 상태를 터미널로 출력한다.

printf("Hello STM32!\r\n");
UART_PrintState(currentState);

\r\n은 터미널에서 줄을 바꿀 때 사용하는 Carriage Return과 Line Feed다.

printf와 USART2 연결

STM32에는 PC와 같은 기본 콘솔이 없으므로 _write()를 USART2 송신 함수에 연결했다.

int _write(int file, char *ptr, int len)
{
    (void)file;

    if (HAL_UART_Transmit(&huart2,
                          (uint8_t *)ptr,
                          (uint16_t)len,
                          HAL_MAX_DELAY) == HAL_OK)
    {
        return len;
    }

    return -1;
}
printf() → _write() → HAL_UART_Transmit() → USART2 → PC 터미널
printf("Command: %s\r\n", command);
printf("State: %s\r\n", stateName);

UART 인터럽트 수신

if (HAL_UART_Receive_IT(&huart2, &receivedByte, 1U) != HAL_OK)
{
    Error_Handler();
}

IT는 Interrupt를 의미한다. 문자가 도착하면 USART2 IRQ Handler를 거쳐 수신 완료 콜백이 실행된다.

문자 도착 → USART2_IRQHandler() → HAL_UART_IRQHandler() → HAL_UART_RxCpltCallback()
HAL_NVIC_SetPriority(USART2_IRQn, 0, 0);
HAL_NVIC_EnableIRQ(USART2_IRQn);

void USART2_IRQHandler(void)
{
    HAL_UART_IRQHandler(&huart2);
}

수신 완료 콜백과 문자열 버퍼

#define UART_RX_BUFFER_SIZE 32U

static uint8_t receivedByte;
static char uartRxBuffer[UART_RX_BUFFER_SIZE];
static volatile uint8_t uartRxIndex = 0U;
static volatile uint8_t uartCommandReady = 0U;

수신한 문자를 버퍼에 저장하고 인덱스를 다음 위치로 이동한다.

uartRxBuffer[uartRxIndex] = (char)receivedByte;
uartRxIndex++;

Enter에 해당하는 \r 또는 \n을 받으면 문자열 끝에 \0을 추가한다.

if ((receivedByte == '\r') || (receivedByte == '\n'))
{
    if (uartRxIndex > 0U)
    {
        uartRxBuffer[uartRxIndex] = '\0';
        uartCommandReady = 1U;
    }
}
'l' → 'e' → 'd' → ' ' → 'r' → 'e' → 'd' → Enter → "led red\0"

버퍼는 32바이트이며 최대 31글자의 명령을 저장한다. 범위를 넘으면 Command too long을 출력한다.

문자열 명령 처리

strcmp()는 두 문자열이 같을 때 0을 반환한다.

if (strcmp(command, "led green") == 0)
{
    currentState = LED_STATE_IDLE;
}
else if (strcmp(command, "led red") == 0)
{
    currentState = LED_STATE_ERROR;
}
명령동작
led green초록색 LED, IDLE
led blue파란색 LED, RUNNING
led yellow노란색 LED, WARNING
led red빨간색 LED, ERROR
status현재 상태 출력
help사용 가능한 명령 출력

전체 동작과 배운 점

인터럽트 수신 등록 → 한 바이트씩 수신 → 버퍼 저장 → Enter에서 명령 완성 → LED 상태 변경 → printf() 출력
  • HAL_UART_Receive_IT()로 반복문을 막지 않고 데이터를 받을 수 있다.
  • 수신 완료 콜백에서는 짧은 작업만 수행하고 명령은 while (1)에서 처리한다.
  • 문자 배열 끝에 \0을 추가하면 C 문자열이 된다.
  • strcmp()는 같은 문자열에 대해 0을 반환한다.
  • _write()를 USART2에 연결하면 printf()를 사용할 수 있다.

USART2 인터럽트로 문자를 한 바이트씩 받아 문자열 명령을 구성하고, LED 상태를 변경한 뒤 UART로 결과를 출력하도록 구현했다.
