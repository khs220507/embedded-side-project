STM32 Timer: TIM2 Interrupt 기반 ADC Sampling

TIM2 Update Interrupt로 CdS 센서의 500ms 측정 시점을 만드는 범위를 정리한다.

기본 개념핵심 코드실행 흐름검증 상태

기본 개념

TIM2는 MCU 내부 Clock을 센다. APB1 Timer Clock 84MHz를 Prescaler 8399로 나누면 10kHz가 되고, Period 4999까지 5,000번 세면 500ms가 된다. 레지스터 값은 실제 계산에서 각각 +1을 적용한다.

핵심 코드

HAL_TIM_Base_Start_IT(&htim2);

초기화가 끝난 TIM2 Counter와 Update Interrupt를 실제로 시작한다.

void TIM2_IRQHandler(void)
{
    HAL_TIM_IRQHandler(&htim2);
}

void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
{
    if (htim->Instance == TIM2)
    {
        timerSampleRequested = 1U;
    }
}
if (timerSampleRequested != 0U)
{
    timerSampleRequested = 0U;
    CdS_ProcessSample();
}

단계실행 주체하는 일
1main()HAL_TIM_Base_Start_IT()로 Counter를 시작한다.
2TIM2 하드웨어Main Loop와 별개로 500ms를 센다.
3MCU시간이 끝나면 Main Loop를 잠깐 멈추고 TIM2_IRQHandler()를 자동 실행한다.
4HAL CallbacktimerSampleRequested = 1U만 설정한다.
5main()Interrupt가 끝난 뒤 멈췄던 while (1) 자리로 돌아와 ADC·LED·UART를 처리한다.

Interrupt 안에서는 시간이 걸릴 수 있는 ADC Polling과 printf()를 실행하지 않는다. Callback은 짧게 끝내고 실제 작업은 Main Loop에 맡긴다.
