STM32 ADC: CdS 조도 센서 측정

PA0의 Analog Output을 12-bit 값으로 변환하고 UART로 확인하는 범위를 정리한다.

기본 개념구현 목표배선핵심 코드동작 흐름LED 단계검증 상태정리

기본 개념

ADC는 Analog-to-Digital Converter의 약자로, 연속적인 전압을 MCU가 처리할 수 있는 정수값으로 변환한다. 04_ADC_CdS에서는 CdS 모듈의 Analog Output을 PA0(ADC1_IN0, Arduino A0)에서 읽는다.

12-bit 결과 범위는 0~4095이며, 현재 코드는 기준 전압을 3300mV로 가정해 원시값 × 3300 ÷ 4095로 전압을 계산한다. 실제 VDDA와 ADC 오차를 보정한 정밀 측정값은 아니다.

구현 목표

  • PA0를 ADC1_IN0 Analog Input으로 사용한다.
  • ADC1을 12-bit 단일 변환, Software Trigger 방식으로 설정한다.
  • 500ms마다 CdS 값을 측정한다.
  • 원시값과 환산 전압을 USART2 DMA 기반 printf()로 출력한다.

핵심 코드

ADC1 초기화

hadc1.Instance = ADC1;
hadc1.Init.ClockPrescaler = ADC_CLOCK_SYNC_PCLK_DIV4;
hadc1.Init.Resolution = ADC_RESOLUTION_12B;
hadc1.Init.ScanConvMode = DISABLE;
hadc1.Init.ContinuousConvMode = DISABLE;
hadc1.Init.ExternalTrigConv = ADC_SOFTWARE_START;
hadc1.Init.DataAlign = ADC_DATAALIGN_RIGHT;
hadc1.Init.NbrOfConversion = 1;

channelConfig.Channel = ADC_CHANNEL_0;
channelConfig.Rank = 1;
channelConfig.SamplingTime = ADC_SAMPLETIME_84CYCLES;

APB2 84MHz를 4분주한 21MHz ADC Clock을 사용한다. 한 Channel만 읽으므로 Scan과 Continuous Conversion을 끄고 측정 시점마다 Software로 변환을 시작한다.

단일 값 읽기

HAL_ADC_Start(&hadc1);
HAL_ADC_PollForConversion(&hadc1, 10U);
rawValue = HAL_ADC_GetValue(&hadc1);
HAL_ADC_Stop(&hadc1);

변환을 시작하고 완료를 Polling한 뒤, 성공했을 때만 12-bit 결과를 읽고 ADC를 정지한다.

500ms 주기 출력

if ((HAL_GetTick() - lastSensorSampleTime) >= 500U)
{
    uint32_t rawValue;
    lastSensorSampleTime = HAL_GetTick();

    if (ADC_ReadCdS(&rawValue) == HAL_OK)
    {
        uint32_t millivolts = (rawValue * 3300U) / 4095U;
        currentState = CdS_GetBrightnessState(rawValue);
        LED_ShowState(currentState);
        printf("CdS raw=%lu, voltage=%lu mV, brightness=%s\r\n",
               (unsigned long)rawValue,
               (unsigned long)millivolts,
               CdS_GetBrightnessName(currentState));
    }
}

HAL_Delay() 대신 Tick 차이를 사용하므로 기존 버튼 입력과 UART 명령 처리도 계속 실행된다.

조도 단계 LED 표시

밝을 때 raw=252~308, 어두울 때 raw=3657~3881을 실제로 측정했다. 이 모듈은 ADC 값이 클수록 어두운 상태이므로, 두 끝값 사이를 네 구간으로 나눠 기존 4색 LED 회로에 연결했다.

밝은 상태에서 ADC 값이 낮고, 어두운 상태에서 높아지는 것을 확인했다. 새 Firmware를 Flash한 뒤 각 조도 구간에서 LED와 brightness 출력이 일치하는지 확인한다.

배운 점

  • Analog Input은 HIGH/LOW가 아니라 전압 범위를 수치로 표현한다.
  • 12-bit ADC는 입력 범위를 4096단계로 나눈다.
  • Channel은 물리 입력 경로이고 Rank는 변환 순서다.
  • Polling 방식은 단순하지만 완료될 때까지 CPU가 기다린다.
  • 센서 임계값은 실제 측정 범위를 확인한 후 정해야 한다.

한 줄 정리

PA0의 CdS Analog Output을 ADC1의 12-bit 값으로 변환하고, 500ms마다 원시값과 환산 전압을 UART로 확인한다.
