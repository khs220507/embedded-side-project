STM32 PWM: CdS 기반 LED 밝기 제어

TIM1 Channel 1 PWM과 CdS ADC 값을 연결해 PA8 빨간 LED 밝기를 자동으로 제어한다.

기본 개념구현 목표배선핵심 코드동작 흐름실행 결과

기본 개념

PWM은 일정한 주기 안에서 HIGH 시간의 비율인 Duty Cycle을 바꿔 평균 출력량을 조절하는 방식이다. LED는 Duty Cycle이 높을수록 더 밝게 보인다.

06_PWM_LED에서 TIM2는 500ms 측정 시점만 만들고, TIM1은 PA8에 1kHz PWM을 출력한다.

Timer역할실제 처리
TIM2측정 시점 생성Update Interrupt에서 Flag 설정
TIM1LED 밝기 생성PA8(D7)에 PWM 출력

구현 목표

  • PA8(D7)의 빨간 LED를 TIM1_CH1 PWM으로 구동한다.
  • CdS ADC 값 0~4095를 PWM Compare 값 0~1000으로 변환한다.
  • 밝을 때는 LED를 어둡게, 어두울 때는 밝게 만든다.

배선

NUCLEO D7 (PA8) → 220Ω 저항 → 빨간 LED Anode(긴 다리)
빨간 LED Cathode(짧은 다리) → GND

PA8은 일반 GPIO가 아니라 TIM1_CH1 Alternate Function 출력으로 사용한다.

핵심 코드

1. TIM1 PWM 설정

#define PWM_PERIOD 999U
htim1.Init.Prescaler = 83;
htim1.Init.Period = PWM_PERIOD;
channelConfig.OCMode = TIM_OCMODE_PWM1;
HAL_TIM_PWM_ConfigChannel(&htim1, &channelConfig, TIM_CHANNEL_1);
HAL_TIM_PWM_Start(&htim1, TIM_CHANNEL_1);

84MHz ÷ (83 + 1) = 1MHz이고, 1MHz ÷ (999 + 1) = 1kHz PWM이다.

2. PA8을 TIM1_CH1로 연결

GPIO_InitStruct.Mode = GPIO_MODE_AF_PP;
GPIO_InitStruct.Alternate = GPIO_AF1_TIM1;

이 설정 뒤 PA8의 출력은 Timer가 제어한다.

3. ADC 값을 Duty Cycle로 변환

pulse = (rawValue * (PWM_PERIOD + 1U)) / 4095U;
__HAL_TIM_SET_COMPARE(&htim1, TIM_CHANNEL_1, pulse);

주의 사항과 배운 점

PA8은 PWM 출력 전용 핀이다. 이전 GPIO 방식의 LED_ShowState() 또는 UART led red 명령은 빨간 LED PWM을 직접 바꾸지 못한다. 빨간 LED의 밝기는 PWM_SetDutyFromCdS()가 관리한다.

  • PWM 밝기는 Counter Period와 Compare 값의 비율로 결정된다.
  • PWM 출력에는 Timer Alternate Function 핀 설정이 필요하다.
  • ADC와 PWM 범위가 다르면 값 변환이 필요하다.

한 줄 정리

TIM2가 500ms마다 CdS 측정을 요청하고, Main Loop가 ADC 값을 TIM1_CH1 Duty Cycle로 바꿔 PA8 빨간 LED 밝기를 자동 제어한다.
